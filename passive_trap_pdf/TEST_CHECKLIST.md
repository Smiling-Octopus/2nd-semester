# 검토 체크리스트

이 목록은 기존 ZIP의 성공 예상표를 대체합니다. 서버에 직접 보낸 테스트 요청과 PDF 뷰어의 실제 요청을 혼동하지 않습니다.

## 최초 ZIP 반영에서 확인한 항목 — 2026-10-13

- [x] ZIP 무결성 및 경로·심볼릭 링크 검사
- [x] Python 소스 2개 구문 검사 및 ZIP 원본과 SHA-256 일치
- [x] 소켓 사용을 차단한 프로세스 내 Flask test client로 `/track`, `/pixel` 각각 HTTP 200, `image/gif`, `no-store` 응답 확인
- [x] 합성 테스트 요청에 대한 임시 로그 2줄 확인 — 실제 문서 열람 로그 아님
- [x] 반환 GIF를 Pillow로 디코딩하여 1×1 크기 확인
- [x] 격리 임시 폴더에서 생성기 실행: 파일 생성됨
- [x] 생성 PDF 엄격 파싱 검사 실시: **실패**, `PdfReadError: Trailer cannot be read: '/Type'`
- [x] 기존 `benign_pdf_js` Python 5개 검사, Node 모의 검사, 체크섬 검사 통과

## 원본 초안 및 남은 검증

- [ ] PDF 구조가 유효한지 재검증 — 현재 실패 상태이며 통과로 기록하지 않음
- [ ] 동의된 테스트베드에서 뷰어 제품명·전체 버전·보안 기본 설정 기록
- [ ] 보존된 원본 초안 자체의 정상 JavaScript 이벤트 연결과 자동 통신 검증 — 별도 진단 PDF 결과로 대체하지 않음
- [ ] 원래 목표를 충족하는 자동 요청의 시각·시험 파일 SHA-256·서버 관측 연결 — 현재 성공 사례 없음
- [ ] 재열람 결과, 보안 경고, 미지원/차단/오류 구분 기록
- [ ] Acrobat/Foxit 실제 뷰어 검증

## Windows 후속 기록에서 확인한 항목 — 2026-10-23

- [x] Windows 11 Pro 및 Chrome·Edge 전체 버전, GUI/headless 조건과 실제 관측 시간 확인
- [x] 초기 원본의 Edge 본문 표시 및 자동 요청 0건 기록 — Chrome 초기 표시는 대조군도 불확정
- [x] 별도 수정 대조군의 엄격 파싱·한글 표시·Chrome/Edge 명시적 링크 수신 2건 확인
- [x] 별도 수정 대조군 테스트 3개 및 전달 사본 테스트 3개 통과 기록 확인 — 보존된 원본의 통과 판정 아님
- [x] 유효한 별도 PDF의 열림 JavaScript 실행과 자동 폼 전송의 사용자 동작 요구 오류 확인
- [x] Chrome·Edge × 서버/로컬 파일의 외부 이미지 4조건 측정 — 자동 요청 0건, HTML 자원 대조 8건 성공
- [x] GUI URI·폼 액션 및 다운로드한 로컬 PDF의 외부 문서 참조 추가 관측 — 자동 요청 미관측
- [x] XFA 내장 기준선 미표시 기록 — 정상 처리 후 외부 통신 차단으로 판정하지 않음
- [x] REA·Ghidra 정적 분석과 별도 GUI 무입력 60.11초 관측의 결과 구분
- [x] 원시 OCR의 false 값 보존 및 원본 화면의 별도 직접 판독 기록 확인
- [x] 시험 프로세스·포트 종료 및 기존 브라우저 유지 기록 확인
- [x] 공개용 근거 요약의 원본 자료 해시와 저장소 원본 Python 해시 대조

상세 결과와 한계는 [Windows 검증 기록](WINDOWS_VALIDATION_20261023.md)에 있습니다. 최신 결과 전체를 `NOT_TESTED`로 표시하지 않으며, **원래의 무입력 자동 전송 목표는 미달성**으로 기록합니다. 결과를 얻기 위해 보호 모드를 끄거나 신뢰 위치를 추가하거나 외부 제3자에게 문서를 전송하지 않습니다. 위 항목은 검토 기준이며 자동 실행 또는 새 작업 등록을 의미하지 않습니다.
