# Windows 환경에서 PDF를 활용한 공격자 정보 수집 및 위협 대응 기법

배재대학교 소프트웨어공학부(정보보안학)의 산학캡스톤디자인2 팀 **웃는 문어**의 프로젝트 저장소입니다.

## 프로젝트 개요

침해사고 대응 과정에서 피해 시스템의 로그와 이미 알려진 위협 정보만으로는 공격자 측의 시스템 및 통신 정보를 충분히 확보하기 어렵습니다. 이 프로젝트는 통제된 테스트베드에서 PDF 열람을 계기로 동작하는 정보 수집 프로그램과 분석 서버를 구성하고, 수집 정보의 분석 및 위협 대응 연계 가능성을 검증하는 것을 목표로 합니다.

수집된 정보는 분석 서버에서 통합 관리하며, IP 위치정보, ASN, 프로세스와 통신 대상의 관계를 분석·시각화하는 방안을 검토합니다. 프로젝트 결과는 구현 결과와 실험 결과를 구분하여 기록하고, 환경별 제약사항과 해석상의 한계를 함께 정리합니다.

> 본 프로젝트의 모든 구현과 실험은 VirtualBox 테스트베드에서만 수행합니다. 실제 시스템, 제3자 문서 또는 운영 중인 네트워크를 대상으로 사용하지 않습니다.

## 현재 상태

프로젝트 수행 전 단계입니다. 초기 설계와 요구사항을 정리한 뒤 개발 환경을 구축하고, 수집 프로그램·서버·분석 기능을 단계적으로 구현할 예정입니다.

## 대상 환경

| 구분 | 환경 |
| --- | --- |
| PC | Microsoft Windows 11 |
| 서버 | Kali Linux 또는 Ubuntu Linux |
| 가상화 | Oracle VirtualBox |

## 개발 환경

- Python 3.x
- JavaScript 또는 PowerShell
- Python 라이브러리: `pypdf`, `pdfrw`
- Visual Studio Code
- Oracle VirtualBox

## 예정 기능

- Windows 기반 정보 수집 프로그램
- Linux 기반 정보 수집 서버
- PDF와 수집 프로그램의 연계
- 시스템, 프로세스 및 통신 관련 정보의 수집·전송·저장
- 수집 정보의 출처와 관측 시각 관리
- IP 위치정보 및 ASN 결합
- 프로세스와 통신 대상 간 관계 분석 및 시각화
- 위협 지표 기반 경보와 통신 차단 정책 연계
- 통제된 시나리오 기반 통합 실험 및 결과 검증

## 개발 및 검증 범위

프로젝트는 다음 순서로 진행할 예정입니다.

1. 선행연구 조사 및 모의 시나리오 구상
2. 시스템 아키텍처와 기능요구사항 정의
3. VirtualBox 기반 Windows/Linux 테스트베드 구축
4. 정보 수집 프로그램 및 분석 서버 설계
5. 정보 수집·전송·저장 기능 개발
6. 분석, 시각화, 경보 및 정책 연계 기능 검토
7. 시나리오 기반 실험과 제약사항 검증
8. 결과 정리 및 최종 보고서 작성

## 저장소 구조

프로젝트 관련 코드는 기능에 따라 다음 세 디렉터리로 구분합니다.

```text
2nd-semester/
├─ System Information Gathering/  # Windows 시스템 정보 수집 프로그램
├─ PDF File Script Code/           # PDF 파일 및 스크립트 연계 코드
├─ Server/                         # Linux 정보 수집·분석 서버
└─ README.md
```

각 디렉터리의 역할은 다음과 같습니다.

| 디렉터리 | 역할 |
| --- | --- |
| `System Information Gathering` | Windows 환경에서 시스템, 프로세스 및 통신 정보를 수집하는 프로그램 개발 |
| `PDF File Script Code` | 통제된 테스트용 PDF와 PDF 연계 스크립트 코드 관리 |
| `Server` | Linux 환경에서 수집 정보의 수신, 저장, 분석 및 시각화 기능 개발 |

## 코딩 컨벤션

- 변수, 함수, 파일 및 디렉터리 이름은 스네이크 표기법을 사용합니다.
- 함수와 주요 기능에는 동작을 설명하는 짧은 주석을 작성합니다.
- 수집한 정보는 관측 사실, 분석 결과, 정책 적용 결과를 구분하여 기록합니다.
- 환경별 실행 조건과 실패 원인을 실험 기록에 남깁니다.
- 구현 및 문서 변경 사항은 기능 단위로 정리합니다.
- 커밋 메시지는 `이름 : 작업 내용` 형식으로 작성합니다.
	- 예시 : `홍길동 : Windows 파일 송신 기능 구현(추가)`
	- 예시 : `홍길동 : Windows 파일 송신 기능 코드 수정(버그 수정)`
	- 예시 : `홍길동 : Windows 파일 송신 기능 코드 수정(코드 리팩토링)`
