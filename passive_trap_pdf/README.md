# Qwen PDF 원본 초안 및 Windows 후속 검토

> **상태: `UNVERIFIED_DRAFT` / 사용 가능한 완성본 아님.**
> 이 폴더는 제공된 `qwen-next-workspace.zip`의 Python 소스 보존·검토용입니다.
> 보존된 원본 생성물은 엄격 PDF 파싱 검사에 실패했습니다.
> 2026-10-23 Windows 후속 실험은 진행했지만, **로컬 PDF 열람만으로 자동 전송하는 목표는 미달성**입니다.

## 최신 검토 결과 — 2026-10-23

- [Windows 후속 실험 및 분석 결과](WINDOWS_VALIDATION_20261023.md): 원본 시험, 별도 수정 대조군, 자동 전송 후보와 REA·Ghidra 정적 분석을 구분합니다.
- [5주차 진행 요약](WEEKLY_PROGRESS.md): 실제 날짜 배정 없이 작업 순서를 5개 주차로 재구성했으며 각 주차는 3줄입니다.
- [공개용 근거 요약](evidence/2026-10-23/summary.json): 원시 기록에서 추출한 관측값과 원본 자료의 SHA-256을 제공합니다. 전체 원시 로그를 대신하는 재현 패키지는 아닙니다.

별도 작업공간에서는 PDF 구조와 한글 표시를 수정하고 Chrome·Edge의 명시적 링크 수신 2건을 확인했습니다. 해당 수정본은 클릭형 대조군이며 원래 자동 전송 목표를 충족하지 않습니다. **이 저장소의 두 Python 파일은 ZIP 원본 보존본으로 유지**하므로, 수정본의 통과 결과를 이 파일들의 결과로 적용하지 않습니다.

유효한 별도 진단 PDF에서는 문서 열림 JavaScript 실행을 확인했습니다. 그러나 시험한 `getURL`, 자동 폼 전송, 외부 이미지·문서 참조에서는 무입력 자동 요청을 관측하지 못했습니다. XFA는 내장 기준 화면도 표시되지 않아 해당 처리 경로가 실행됐는지 미확정입니다.

## 기존 실험과 구분

- `../benign_pdf_js/`: 외부 통신·개인정보 수집 없는 기존 JavaScript 호환성 실험. 이번 반영에서 변경하지 않았습니다.
- 이 폴더: `/track`, `/pixel` 수집 서버와 PDF 생성기 초안. Python 파일은 ZIP 내부 `passive_trap_pdf/` 원본과 바이트 단위로 동일하며, 기능을 수정하거나 보강하지 않았습니다.
- 원본 README·체크리스트의 검증되지 않은 성공 단정은 그대로 게시하지 않고, 아래 사실 및 검증 범위로 정정했습니다.

## 반드시 구분할 사실

1. 생성기의 `drawImage("1x1.gif", ...)`는 **로컬 이미지를 PDF에 삽입**합니다. `pixel_url`은 계산·출력만 되고 외부 이미지 참조로 연결되지 않습니다. 따라서 이 코드로 PDF를 열면 모든 뷰어에서 `/pixel` 요청이 발생한다는 설명은 성립하지 않습니다.
2. PDF 생성 함수가 끝났다는 것과 유효한 PDF가 생성됐다는 것은 다릅니다. 보존된 원본 초안의 생성물은 `pypdf.PdfReader(..., strict=True)`에서 `PdfReadError`가 발생했습니다.
3. PDF JavaScript 실행과 외부 통신 허용은 별개입니다. 코드에 `getURL`이 있다는 사실만으로 무경고·백그라운드 전송이나 Acrobat/Foxit 동작을 보장하지 않습니다.
4. `Cache-Control: no-store`는 실제 HTTP 응답의 캐시 정책일 뿐, PDF 재열람마다 요청이 발생한다는 증거가 아닙니다.
5. 서버 로그가 없다는 사실만으로 오프라인 열람을 판정할 수 없습니다. 뷰어 미지원, 보안 정책, 네트워크 차단, 코드 오류 등도 가능합니다.
6. IP·User-Agent는 신원 또는 기기 종류를 확정하는 증거가 아닙니다. 이 서버는 `X-Forwarded-For`를 그대로 신뢰하므로 로그의 IP도 검증된 관측값으로 단정할 수 없습니다.

## 사용 경계

저장소 공통 정책대로 신규 실험은 동의된 VirtualBox 테스트베드에서 검토합니다. 실제 제3자 추적·기관 위장·보호 설정 해제에 사용하지 않습니다. 최초 ZIP 반영에서는 서버 리슨이나 실제 뷰어 실행을 하지 않았습니다. 2026-10-23 후속 기록은 별도 Windows 11 Pro 실험 호스트에서 수행한 결과이며, 그 호스트의 VirtualBox 사용 여부는 보존 자료로 확인되지 않았습니다. 이를 저장소의 VirtualBox 환경 검증 완료로 기록하지 않습니다. 이번 업데이트는 기존 기록을 문서화한 것이며 새 원격 실험을 실행하지 않았습니다.

`server.py`를 직접 실행하면 `0.0.0.0:5000`에 바인딩하도록 작성되어 있습니다. 검토 완료 전 운영하거나 인터넷에 공개하지 않습니다. 파일 보존이 배포 승인이나 기능 검증을 뜻하지 않습니다.
